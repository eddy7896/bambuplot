    Orientation

    A5 is longer than the plate. The hatched part hangs off the edge with nothing under it, so the pen can't draw there.

    Pen holder (clip-on, rigid)

    Offset is pen tip minus nozzle (+X right, +Y toward the back). Without a spring, keep the press at 0.1–0.2 mm. Print the press ladder from the Job panel to find yours.

    Clips

      Drawing area

      Drag the round knob above a selected shape to rotate it (Shift snaps to 15°). Or press [ and ] to turn it 1° (with Shift, 15°).

      Motion

      Feeds are mm/min, acceleration mm/s². Lower values reduce ringing on the cantilever arm.

      Connection

      On the printer, turn on LAN Only mode; its screen shows the IP address and access code. To start jobs from here, also turn on Developer Mode and restart the printer. Developer Mode disconnects the Bambu cloud and the Handy app while it's on.

      The access code is stored only on this computer, in a file only you can read. It is never sent back to the page.

      Project template

      No template yet. Plain .gcode will be uploaded.

      Bambu printers start jobs from .gcode.3mf files. In Bambu Studio, slice any small model for the A1 mini, then choose File → Export → Export plate sliced file. BambuPlot puts each plot inside that file. Nothing from the model gets printed.

      Advanced

      Leave this as file:///sdcard/ unless uploads work but jobs won't start. Some firmware expects ftp:/// instead.

      Open in Bambu Connect sends the job through your Bambu account, so it works away from home. You pick the printer in Bambu Connect. Upload only and Upload and start use your local network.

      Starting a job makes the printer home right away. The pen holder must be empty and nothing can be near the nozzle. The pen goes in at Pause 1.

      1. Home happens first with no pen in the holder.
      2. Pause 1 at the red cross: clip the paper, push the pen down until it touches, tighten.
      3. Pause 2 after the outline trace: check where the drawing will land.
      4. Pause 3 after the small L mark: re-seat the pen if the line is faint.

      Time ignores acceleration, so real jobs run a little longer. Run the smoke test first on new hardware.
