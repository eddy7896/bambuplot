        Connection

        On the printer, turn on LAN Only mode; its screen shows the IP and access code. To start jobs from here, also turn on Developer Mode and restart the printer. The code is stored only on this Mac.

        Project File (.gcode.3mf)

        BambuPlot writes the whole project file: the plot, a thumbnail, the printer model, the time estimate and the pause count. No slicer needed.

        No template yet.

        In Bambu Studio, slice any small model for your printer, then File → Export → Export plate sliced file. BambuPlot swaps in the plot.

        Printer Screen

        The printer can't show your own words, only its built-in messages. Homing shows "Homing toolhead" and drawing shows "Printing". The G-code comments at each pause still say exactly what to do.

        Safety Checks

          Send to Printer

          1. The printer homes first, so the pen holder must be empty.
          2. Pause 1 at the red cross: clip the paper, push the pen down until it touches, tighten.
          3. Pause 2 after the outline trace: check where the drawing will land.
          4. Pause 3 after the small L mark: re-seat the pen if the line is faint.
